# site-optimus

Site institucional da Optimus Aprendizado (ANIVOM TECNOLOGIA LTDA), no ar em https://www.optimusaprendizado.com.br.

- Detalhes, regras e decisões estão no [`CLAUDE.md`](CLAUDE.md).
